# Accessibility

## Scope and current status

This repository primarily provides an HTTP API. It also contains Keycloak login and account-related theme assets. Theme changes should preserve form labels, keyboard operation, visible focus, readable error messages, and compatibility with assistive technology.

There is no documented comprehensive accessibility audit or verified WCAG conformance assessment for this repository. Known barriers are tracked through issues; the absence of an issue is not evidence that a flow is accessible.

## Report a barrier

Report barriers in the bundled Keycloak theme here, including the affected authentication flow, browser, and assistive technology if relevant. Report barriers in the main web interface in [Meterya App](https://github.com/roman-kiefer/meterya-app/issues/new/choose).

Use the [bug report form](https://github.com/roman-kiefer/meterya-api/issues/new?template=bug_report.yml). If the form itself prevents reporting, open a [blank issue](https://github.com/roman-kiefer/meterya-api/issues/new). No personal medical information is needed. Remove private data from attachments.

## Contributing improvements

Include accessibility considerations when changing controls, navigation, error feedback, or documentation. Describe the affected task and the keyboard or assistive-technology checks actually performed. See [CONTRIBUTING.md](CONTRIBUTING.md) for the contribution process.
